CloudCorpRecords

Open-source tools by Rene Turcios, San Francisco. The work measures what actually stops AI agents on the web — bot walls, agent-contribution policy, package health — and publishes the receipts: deterministic probes, named vendors, shown evidence. No bypass tooling, no evasion, no spoofing; the fight is measurement, signed agent identity (Web Bot Auth, RFC 9421), and documented front doors.

For machines

This site publishes the files the campaign asks every site for: robots.txt, llms.txt, sitemap.xml, an RSS feed, and a Web Bot Auth key directory at /.well-known/http-message-signatures-directory. It has no API; the honest record of that absence is the audit itself.
